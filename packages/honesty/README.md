# @ceccec/honesty — the method

Reusable tests for any bold claim (the *method* vertex of the trinity:
**substrate** `millennium-solutions` · **method** `@ceccec/honesty` · **meaning** `@ceccec/millennium-vision`).

- `entails(trueWhenConjectureFalse)` — does a statement entail its conjecture, or hold regardless?
- `curveFitCheck(target, consts, ints?, control?)` — is a "prediction" just a fit that hits anything?
- `scaleCheck(a, b)` — how many orders of magnitude apart are two quantities?
