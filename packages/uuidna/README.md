# uuidna

**Content-addressed identity.** Every claim in this file is a statement paired with a decidable test; each
one is put through `adjudicate()` and appears only if the verdict is SEALED — gate-clean *and* its test
holds. The file is generated by `readme.mjs`, which fails rather than write an unsealed sentence.

That indirection is the point. The prose gate matches the *shape* of an overclaim, so it passes
`"two plus two equals five"` — and it passed an earlier version of this README whose wording described
behaviour the functions do not implement. A shape check cannot catch an inaccuracy written in ordinary
words; a test can.

```bash
npm install @uuidna/uuidna
```

## What it does

- The same input mints the same address for anyone, with no key — a content-address is reproducible, not secret.
  <sub>SEALED · `bbeaec0a-183e-8915-ada2-1ac5bff5416d`</sub>
- The address is a pure function of the input text, so two runtimes that agree on the text agree on the address.
  <sub>SEALED · `8fd47f83-7ec7-811b-be0c-d498f1db0c0b`</sub>
- Folding a set of addresses is order-independent: any ordering of the same leaves gives the same root.
  <sub>SEALED · `3682ce5a-de77-8055-ba87-f42b18845cd6`</sub>

## Merkle inclusion proof

- A Merkle inclusion proof shows that ONE named leaf belongs to the set, and its size grows with the logarithm of the set.
  <sub>SEALED · `b207e7f3-bffa-882c-b3be-0f59dc2c79ff`</sub>
- A leaf that is not in the set fails to verify against the root.
  <sub>SEALED · `c7b320c2-e210-803d-aed1-c138fb1bd00c`</sub>

## Imprint codec

- The imprint codec writes text into a chain of uuids and reads it back unchanged — a reversible public encoding, not encryption.
  <sub>SEALED · `18eb1719-a2d4-8e57-bcff-7ebfc7ae0c8e`</sub>
- One uuid carries at most 115 bits of message, so longer text is split across several.
  <sub>SEALED · `49701198-e329-894d-9a45-a7cde171f0f6`</sub>

## Encryption

- Encryption is ChaCha20-Poly1305 with a PBKDF2-SHA256 key, written in TypeScript with no native crypto call, and it round-trips.
  <sub>SEALED · `b6d8c806-c9f0-8b35-8763-ed591782e364`</sub>
- A wrong passphrase or a tampered ciphertext throws rather than returning wrong plaintext.
  <sub>SEALED · `5455056e-f7e2-8fe3-8c15-f07dc3747183`</sub>
- The default mode is convergent: the same plaintext under the same passphrase produces the same envelope, which means an observer can tell when two envelopes hold identical plaintext.
  <sub>SEALED · `edd0ce97-ce61-85bf-9db8-6a1d70db81bd`</sub>
- The randomized mode hides that equality, at the cost of no longer being reproducible.
  <sub>SEALED · `8af3fbf4-703f-8652-bdd6-7657ddb71890`</sub>
- The SHA-256 used here matches the published FIPS 180-4 digest for the string abc.
  <sub>SEALED · `12454176-9ff5-8030-a835-1b781a5fea36`</sub>

## The prose gate — and what it cannot do

- The gate matches the SHAPE of known overclaims, so it drains a named boast.
  <sub>SEALED · `7b0bbb89-b2a2-8e7d-9b25-4cf2a8793304`</sub>
- The gate does not check whether a statement is true: a plainly false sentence passes it.
  <sub>SEALED · `6c3770f3-2de8-864f-9a3b-83cd16e0945c`</sub>
- Reeducate replaces the phrases the gate matched with a placeholder and returns passed when the result is gate-clean; passed therefore means gate-clean, and an overclaim the gate did not match survives untouched.
  <sub>SEALED · `6aad1f87-20cd-8118-88f5-bfe17060e653`</sub>

## Scope

- This package settles none of the seven Millennium problems.
  <sub>SEALED · `938e279a-ab3c-8267-bcc8-fe6e7f55aff0`</sub>
- The address function is not a secret and not a message authentication code: it takes no key.
  <sub>SEALED · `1e522099-6ca1-8c6e-addd-b228b5241db1`</sub>
- Harness records whether an output is reproducible and whether it is gate-clean; it does not judge whether the output is correct.
  <sub>SEALED · `76e91228-a580-878f-82c3-b667b5472723`</sub>
- The seven locale dimensions are labels the library folds over, not a claim about physics.
  <sub>SEALED · `626095ac-d834-853f-a7a0-25b8a5060d22`</sub>

## What is not claimed here

Nothing above asserts that this package is secure against an adversary, that it settles any open problem,
or that the gate can tell truth from falsehood. Those sentences are absent because no test was written that
would seal them.

Pure JavaScript is not constant-time, so timing side-channels are possible. The address function is
non-cryptographic by construction: it is public, keyless and reproducible, which is what makes it useful for
integrity and useless for secrecy.
