capacity.lean ​

src/iso/22739-ledger/capacity.lean · namespace Capacity · 16 theorems · wing the address

WHY THIS FILE EXISTS.

src/iso/iec-9834-8-identifiers/imprint.lean already decides the bit count: FREE.length = 122 ∧ RESERVED.length = 6 ∧ FREE.length + RESERVED.length = 128. That is sealed and it is honest.

WHAT WAS NOT DECIDED ANYWHERE IS WHAT FOLLOWS FROM IT. The number a reader actually quotes is not the bit count — it is the CAPACITY (how many addresses) and the COLLISION EXPONENT (how hard a forgery is), and neither had a theorem. src/iso/iec-9834-8-identifiers/address.lean states 122 correctly in a COMMENT; the ledger, which is what the MCP server, the site and the trial all consume, carried nothing. A gap where the honest figure should be does not stay empty: prose fills it with the container size, 2^128, because 128 is the number printed on the tin.

The gap is exactly a factor of 64 — one doubling per reserved bit — and on the birthday bound it is a factor of 8. Those are not rounding. A claim of 2^128 addresses overstates the space by 64×, and 2^64 overstates the work a collision search faces by 8×.

THIS IS A HEAL, NOT A WITHDRAWAL. Nothing above is being taken back: the container really is 128 bits and imprint.lean's count really is 122. What is added is the cross formula between them, so the honest figure and the nominal one sit in one place where they cannot be quoted apart. After this, writing 2^128 as the capacity contradicts a sealed theorem rather than merely disagreeing with a comment.

No axioms, no Mathlib, no sorry.

Definitions

container := 128    -- the bits a UUID occupies
reserved := 6      -- 4 version + 2 variant, RFC 9562
free := freeOf reserved
reservations := List.range (container + 1)
version := 4        -- the version nibble — reclaimable by cross-mixing a UUID's version field
variant := 2        -- the RFC 9562 variant — the floor a legal UUID cannot reclaim

Theorem 45 (the_container_is_one_hundred_twenty_eight_and_six_are_spent)sealed.

∀r∈reservations,freeOf(r)+r=container∧container-freeOf(r)=r∧free=122∧reserved=6∧free+reserved=container∧container=128
reservations.all (fun r => (freeOf r + r == container) && (container - freeOf r == r)) ∧ free = 122 ∧ reserved = 6 ∧ free + reserved = container ∧ container = 128
LaTeX source
\forall r \in \mathrm{reservations},\; \mathrm{freeOf}\mathopen{}\left(r\right) + r = \mathrm{container} \land \mathrm{container} - \mathrm{freeOf}\mathopen{}\left(r\right) = r \land \mathrm{free} = 122 \land \mathrm{reserved} = 6 \land \mathrm{free} + \mathrm{reserved} = \mathrm{container} \land \mathrm{container} = 128

── 1 · THE COUNT, AGREEING WITH imprint.lean ───────────────────────────────────────────────────────────── THE SPLIT IS EXACT AT EVERY RESERVATION, AND IT IS RECOVERABLE. What is free plus what is spent returns the container, and the container minus what is free returns what was spent — so neither side is an independent number and editing one without the other contradicts the law. 122 is then read off at r = 6.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 46 (the_capacity_is_two_to_the_free_bits_and_not_the_container)sealed.

∀r∈reservations,2freeOf(r)=2container=r=0∧2freeOf(r)≤2container∧2free=5316911983139663491615228241121378304∧2container=340282366920938463463374607431768211456∧2free<2container
reservations.all (fun r => ((2 ^ freeOf r == 2 ^ container) == (r == 0)) && (2 ^ freeOf r ≤ 2 ^ container)) ∧ 2 ^ free = 5316911983139663491615228241121378304 ∧ 2 ^ container = 340282366920938463463374607431768211456 ∧ 2 ^ free < 2 ^ container
LaTeX source
\forall r \in \mathrm{reservations},\; 2^{\mathrm{freeOf}\mathopen{}\left(r\right)} = 2^{\mathrm{container}} = r = 0 \land 2^{\mathrm{freeOf}\mathopen{}\left(r\right)} \le 2^{\mathrm{container}} \land 2^{\mathrm{free}} = 5316911983139663491615228241121378304 \land 2^{\mathrm{container}} = 340282366920938463463374607431768211456 \land 2^{\mathrm{free}} < 2^{\mathrm{container}}

── 2 · SO THE CAPACITY IS TWO TO THE HUNDRED AND TWENTY-SECOND ─────────────────────────────────────────── The figure a reader quotes, decided. Both numbers written out, because "2^122" and "2^128" look alike on a page and the difference between them does not. AND THE CAPACITY FALLS STRICTLY WHENEVER ANYTHING IS RESERVED, AND ONLY THEN. The inequality is not a fact about six: it holds at every positive reservation and turns into equality at exactly one argument, r = 0. A reader who quotes the container size is claiming r = 0, which the layout refutes.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 47 (the_nominal_overstates_the_real_by_two_to_the_reserved)sealed.

∀r∈reservations,2container2freeOf(r)=2r∧2container=2r⋅2freeOf(r)∧2container2free=2reserved∧2reserved=64∧2container=64⋅2free
reservations.all (fun r => (2 ^ container / 2 ^ freeOf r == 2 ^ r) && (2 ^ container == 2 ^ r * 2 ^ freeOf r)) ∧ 2 ^ container / 2 ^ free = 2 ^ reserved ∧ 2 ^ reserved = 64 ∧ 2 ^ container = 64 * 2 ^ free
LaTeX source
\forall r \in \mathrm{reservations},\; \frac{2^{\mathrm{container}}}{2^{\mathrm{freeOf}\mathopen{}\left(r\right)}} = 2^{r} \land 2^{\mathrm{container}} = 2^{r} \cdot 2^{\mathrm{freeOf}\mathopen{}\left(r\right)} \land \frac{2^{\mathrm{container}}}{2^{\mathrm{free}}} = 2^{\mathrm{reserved}} \land 2^{\mathrm{reserved}} = 64 \land 2^{\mathrm{container}} = 64 \cdot 2^{\mathrm{free}}

── 3 · AND THE GAP IS ONE DOUBLING PER RESERVED BIT ────────────────────────────────────────────────────── Not an unexplained discrepancy: the ratio is exactly 2^6, which is what six reserved bits cost, so the overstatement has a cause a reader can check rather than a size they must accept. Stated as ONE DOUBLING PER RESERVED BIT, AT EVERY RESERVATION. The ratio is 2^r for every r the container admits, and the product form says the same thing without a division — so the factor is the reservation itself and 64 is what that law returns when handed the RFC's six.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 48 (the_collision_exponent_follows_the_free_bits)sealed.

∀r∈reservations,container2-freeOf(r)2=r+12∧2⋅freeOf(r)2+freeOf(r)mod2=freeOf(r)∧free2=61∧container2=64∧2free2=2305843009213693952∧2container2=18446744073709551616
reservations.all (fun r => (container / 2 - freeOf r / 2 == (r + 1) / 2) && (2 * (freeOf r / 2) + freeOf r % 2 == freeOf r)) ∧ free / 2 = 61 ∧ container / 2 = 64 ∧ 2 ^ (free / 2) = 2305843009213693952 ∧ 2 ^ (container / 2) = 18446744073709551616
LaTeX source
\forall r \in \mathrm{reservations},\; \frac{\mathrm{container}}{2} - \frac{\mathrm{freeOf}\mathopen{}\left(r\right)}{2} = \frac{r + 1}{2} \land 2 \cdot \frac{\mathrm{freeOf}\mathopen{}\left(r\right)}{2} + \mathrm{freeOf}\mathopen{}\left(r\right) \bmod 2 = \mathrm{freeOf}\mathopen{}\left(r\right) \land \frac{\mathrm{free}}{2} = 61 \land \frac{\mathrm{container}}{2} = 64 \land 2^{\frac{\mathrm{free}}{2}} = 2305843009213693952 \land 2^{\frac{\mathrm{container}}{2}} = 18446744073709551616

── 4 · THE BIRTHDAY BOUND HALVES THE EXPONENT, AND HALVES THE HONEST ONE ───────────────────────────────── A collision is expected near 2^(n/2). Taken on the container that is 2^64; taken on what is actually free it is 2^61 — the number a forgery attempt really faces. AND THE HALVED WORLD LOSES THE CEILING OF HALF THE RESERVATION, NOT HALF OF IT. Stating the drop as r/2 would be wrong on every odd reservation, because the floor division that halves the exponent cannot spend half a bit: the exponent lost is (r+1)/2. So an odd reservation costs a forger exactly what the next even one costs, and 6 and 5 are the same bound. This is the arithmetic the typed 61 was resting on.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 49 (the_birthday_gap_is_half_the_reservation)sealed.

∀r∈reservations,2container22freeOf(r)2=2r+12∧2container22freeOf(r)2=2r2=rmod2=0∧2container22free2=8∧8=2reserved2∧reserved2=3
reservations.all (fun r => (2 ^ (container / 2) / 2 ^ (freeOf r / 2) == 2 ^ ((r + 1) / 2)) && ((2 ^ (container / 2) / 2 ^ (freeOf r / 2) == 2 ^ (r / 2)) == (r % 2 == 0))) ∧ 2 ^ (container / 2) / 2 ^ (free / 2) = 8 ∧ 8 = 2 ^ (reserved / 2) ∧ reserved / 2 = 3
LaTeX source
\forall r \in \mathrm{reservations},\; \frac{2^{\frac{\mathrm{container}}{2}}}{2^{\frac{\mathrm{freeOf}\mathopen{}\left(r\right)}{2}}} = 2^{\frac{r + 1}{2}} \land \frac{2^{\frac{\mathrm{container}}{2}}}{2^{\frac{\mathrm{freeOf}\mathopen{}\left(r\right)}{2}}} = 2^{\frac{r}{2}} = r \bmod 2 = 0 \land \frac{2^{\frac{\mathrm{container}}{2}}}{2^{\frac{\mathrm{free}}{2}}} = 8 \land 8 = 2^{\frac{\mathrm{reserved}}{2}} \land \frac{\mathrm{reserved}}{2} = 3

── 5 · AND THAT GAP IS A FACTOR OF EIGHT ───────────────────────────────────────────────────────────────── Half the reservation, because the exponent was halved: three bits, not six. The general gap is 2^((r+1)/2) by theorem 4, and it equals the tidy 2^(r/2) at EXACTLY the even reservations — decided as an iff in both directions, so the name's word "half" carries the condition under which it is true instead of hiding it. Six is even, which is why the eight is right here and why it would not have been at five or seven.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 50 (the_gap_is_zero_exactly_when_nothing_is_reserved)sealed.

∀r∈{0,…,32},21282128-r=2r∧r=0=21282128-r=1
(List.range 33).all (fun r => (2 ^ 128 / 2 ^ (128 - r) == 2 ^ r) && ((r == 0) == (2 ^ 128 / 2 ^ (128 - r) == 1)))
LaTeX source
\forall r \in \{0,\dots,32\},\; \frac{2^{128}}{2^{128 - r}} = 2^{r} \land r = 0 = \frac{2^{128}}{2^{128 - r}} = 1

── 6 · THE CONTROL: THE GAP MEASURES THE RESERVATION AND NOTHING ELSE ──────────────────────────────────── THE THEOREM THAT STOPS 3 AND 5 FROM BEING ARITHMETIC COINCIDENCES. Reserve nothing and the two figures coincide; reserve more and the gap grows by exactly that much. Decided across every reservation in range, so the relation is the rule and not a property of six.

Proof. by decide — exhausting 33 cases. □

Theorem 51 (the_overclaim_is_this_many_addresses_that_do_not_exist)sealed.

∀r∈reservations,2container-2freeOf(r)=2r-1⋅2freeOf(r)∧2container-2freeOf(r)=0=r=0∧2container-2free=334965454937798799971759379190646833152∧2container-2free=63⋅2free
reservations.all (fun r => (2 ^ container - 2 ^ freeOf r == (2 ^ r - 1) * 2 ^ freeOf r) && ((2 ^ container - 2 ^ freeOf r == 0) == (r == 0))) ∧ 2 ^ container - 2 ^ free = 334965454937798799971759379190646833152 ∧ 2 ^ container - 2 ^ free = 63 * 2 ^ free
LaTeX source
\forall r \in \mathrm{reservations},\; 2^{\mathrm{container}} - 2^{\mathrm{freeOf}\mathopen{}\left(r\right)} = 2^{r} - 1 \cdot 2^{\mathrm{freeOf}\mathopen{}\left(r\right)} \land 2^{\mathrm{container}} - 2^{\mathrm{freeOf}\mathopen{}\left(r\right)} = 0 = r = 0 \land 2^{\mathrm{container}} - 2^{\mathrm{free}} = 334965454937798799971759379190646833152 \land 2^{\mathrm{container}} - 2^{\mathrm{free}} = 63 \cdot 2^{\mathrm{free}}

── 7 · WHAT A CLAIM OF 2^128 ADDRESSES ACTUALLY ASSERTS ────────────────────────────────────────────────── Stated as the difference itself, so the overstatement is a quantity rather than an adjective: writing the container size as the capacity claims this many addresses that do not exist. THE OVERCLAIM IS (2^r − 1) TIMES WHAT EXISTS, at every reservation — so the 63 is not a coincidence of six but one less than the doubling factor, and the difference vanishes exactly at r = 0 where nothing is spent.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 52 (the_bound_is_a_ceiling_on_difficulty_and_not_a_measurement)sealed.

∀r∈reservations,freeOf(r)2<freeOf(r)=1≤freeOf(r)∧freeOf(r)2≤container2∧2free2<2free∧2free2<2container2∧free2<free
reservations.all (fun r => ((freeOf r / 2 < freeOf r) == (1 ≤ freeOf r)) && (freeOf r / 2 ≤ container / 2)) ∧ 2 ^ (free / 2) < 2 ^ free ∧ 2 ^ (free / 2) < 2 ^ (container / 2) ∧ free / 2 < free
LaTeX source
\forall r \in \mathrm{reservations},\; \frac{\mathrm{freeOf}\mathopen{}\left(r\right)}{2} < \mathrm{freeOf}\mathopen{}\left(r\right) = 1 \le \mathrm{freeOf}\mathopen{}\left(r\right) \land \frac{\mathrm{freeOf}\mathopen{}\left(r\right)}{2} \le \frac{\mathrm{container}}{2} \land 2^{\frac{\mathrm{free}}{2}} < 2^{\mathrm{free}} \land 2^{\frac{\mathrm{free}}{2}} < 2^{\frac{\mathrm{container}}{2}} \land \frac{\mathrm{free}}{2} < \mathrm{free}

── 8 · WHAT THIS FILE DOES NOT SAY ─────────────────────────────────────────────────────────────────────── IT SAYS NOTHING ABOUT ANY HASH. The birthday bound above is counting over a space of a stated size; it assumes values are drawn uniformly and it does not test that SHA-256, FNV or anything else produces them that way. A construction whose outputs are not uniform has a WORSE bound than this, never a better one, so the figures here are a ceiling on the difficulty and not a measurement of it. Nor does anything here decide that 2^61 is enough for any purpose — that is a judgement about a threat, and this deposit's rule is that judgements are not typed into theorems. THE CEILING HOLDS WHEREVER ANYTHING IS LEFT, and it stops holding exactly where nothing is. The guard is freeOf r ≥ 1 and not, as this file first asserted, freeOf r ≥ 2: at one free bit the halving still drops strictly, because 1/2 is 0 and 0 < 1. The kernel refused the ≥ 2 form and the ≥ 1 form is the true one — which is the whole reason the condition is decided at every reservation instead of read off 122.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 53 (the_coil_splits_into_version_and_variant)sealed.

∀v∈{0,…,reserved+1−1},v+reserved-v=reserved∧reserved-reserved-v=v∧freeOf(reserved-v)=freeOf(reserved)+v∧version+variant=reserved∧version=4∧variant=2∧reserved=6
(List.range (reserved + 1)).all (fun v => v + (reserved - v) == reserved && reserved - (reserved - v) == v && freeOf (reserved - v) == freeOf reserved + v) ∧ version + variant = reserved ∧ version = 4 ∧ variant = 2 ∧ reserved = 6
LaTeX source
\forall v \in \{0,\dots,\mathrm{reserved} + 1-1\},\; v + \mathrm{reserved} - v = \mathrm{reserved} \land \mathrm{reserved} - \mathrm{reserved} - v = v \land \mathrm{freeOf}\mathopen{}\left(\mathrm{reserved} - v\right) = \mathrm{freeOf}\mathopen{}\left(\mathrm{reserved}\right) + v \land \mathrm{version} + \mathrm{variant} = \mathrm{reserved} \land \mathrm{version} = 4 \land \mathrm{variant} = 2 \land \mathrm{reserved} = 6

the coil is two parts, and they sum to the six already spent. AS A LAW, NOT A READ-BACK: for EVERY split of the reserved register into a version part v and a variant part reserved − v, the parts sum back to the register, either part recovers the other, and reclaiming the v version bits frees exactly v — freeOf (reserved − v) = freeOf reserved + v. RFC 9562's 4 + 2 is one of the seven decided.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 54 (the_variant_floor_frees_one_hundred_twenty_six)sealed.

freeOf(variant)=126∧freeOf(reserved)=free∧freeOf(variant)-freeOf(reserved)=version∧freeOf(variant)-free=version∧free=122
freeOf variant = 126 ∧ freeOf reserved = free ∧ freeOf variant - freeOf reserved = version ∧ freeOf variant - free = version ∧ free = 122
LaTeX source
\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right) = 126 \land \mathrm{freeOf}\mathopen{}\left(\mathrm{reserved}\right) = \mathrm{free} \land \mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right) - \mathrm{freeOf}\mathopen{}\left(\mathrm{reserved}\right) = \mathrm{version} \land \mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right) - \mathrm{free} = \mathrm{version} \land \mathrm{free} = 122

reserve only the variant and the free register is 126 — four more than at the full coil, the version reclaimed.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 55 (the_reclaim_multiplies_the_space_by_two_to_the_version)sealed.

2freeOf(variant)=2version⋅2free∧2freeOf(variant)2free=2version∧2version=16
2 ^ freeOf variant = 2 ^ version * 2 ^ free ∧ 2 ^ freeOf variant / 2 ^ free = 2 ^ version ∧ 2 ^ version = 16

2^{\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right)} = 2^{\mathrm{version}} \cdot 2^{\mathrm{free}} \land \frac{2^{\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right)}}{2^{\mathrm{free}}} = 2^{\mathrm{version}} \land 2^{\mathrm{version}} = 16

the four reclaimed bits multiply the addressable space by 2^4 = 16.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 56 (the_floor_overstatement_is_two_to_the_variant_not_the_reserved)sealed.

2container2freeOf(variant)=2variant∧2variant=4∧2container=4⋅2freeOf(variant)
2 ^ container / 2 ^ freeOf variant = 2 ^ variant ∧ 2 ^ variant = 4 ∧ 2 ^ container = 4 * 2 ^ freeOf variant
LaTeX source
\frac{2^{\mathrm{container}}}{2^{\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right)}} = 2^{\mathrm{variant}} \land 2^{\mathrm{variant}} = 4 \land 2^{\mathrm{container}} = 4 \cdot 2^{\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right)}

at the variant floor the nominal 2^128 overstates the real by 2^2 = 4 — not the 64 of the full coil.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 57 (the_floor_overclaim_is_three_addresses_per_real_one)sealed.

2container-2freeOf(variant)=2variant-1⋅2freeOf(variant)∧2variant-1=3
2 ^ container - 2 ^ freeOf variant = (2 ^ variant - 1) * 2 ^ freeOf variant ∧ 2 ^ variant - 1 = 3
LaTeX source
2^{\mathrm{container}} - 2^{\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right)} = 2^{\mathrm{variant}} - 1 \cdot 2^{\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right)} \land 2^{\mathrm{variant}} - 1 = 3

stated as the overclaim itself: at the variant floor it is three addresses asserted per real one (2^2 − 1).

Proof. by decide — by evaluation; no domain is walked. □

Theorem 58 (the_birthday_bound_rises_to_sixty_three_at_the_variant_floor)sealed.

free2=61∧freeOf(variant)2=63∧freeOf(variant)2-free2=version2∧version2=2
free / 2 = 61 ∧ freeOf variant / 2 = 63 ∧ freeOf variant / 2 - free / 2 = version / 2 ∧ version / 2 = 2
LaTeX source
\frac{\mathrm{free}}{2} = 61 \land \frac{\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right)}{2} = 63 \land \frac{\mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right)}{2} - \frac{\mathrm{free}}{2} = \frac{\mathrm{version}}{2} \land \frac{\mathrm{version}}{2} = 2

the forgery (birthday) bound rises with the reclaim: 2^61 at the full coil, 2^63 at the variant floor.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 59 (the_split_is_recoverable_at_either_floor)sealed.

container-freeOf(variant)=variant∧container-freeOf(reserved)=reserved∧freeOf(variant)+variant=container∧freeOf(reserved)+reserved=container
container - freeOf variant = variant ∧ container - freeOf reserved = reserved ∧ freeOf variant + variant = container ∧ freeOf reserved + reserved = container
LaTeX source
\mathrm{container} - \mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right) = \mathrm{variant} \land \mathrm{container} - \mathrm{freeOf}\mathopen{}\left(\mathrm{reserved}\right) = \mathrm{reserved} \land \mathrm{freeOf}\mathopen{}\left(\mathrm{variant}\right) + \mathrm{variant} = \mathrm{container} \land \mathrm{freeOf}\mathopen{}\left(\mathrm{reserved}\right) + \mathrm{reserved} = \mathrm{container}

the split is recoverable from either side — spend and reclaim are inverse, so neither floor is an independent number (the involution the reflection has on digits, here on the bit account: what is freed, re-spent, returns).

Proof. by decide — by evaluation; no domain is walked. □

Theorem 60 (the_free_hex_handles_are_thirty_of_thirty_two)sealed.

∀n∈{0,…,container4+1−1},4⋅n4=n∧n-2+2=n=decide(2≤n)∧container4=32∧version4=1∧container4-version4+1=30
(List.range (container / 4 + 1)).all (fun n => 4 * n / 4 == n && (n - 2 + 2 == n) == decide (2 ≤ n)) ∧ container / 4 = 32 ∧ version / 4 = 1 ∧ container / 4 - (version / 4 + 1) = 30
LaTeX source
\forall n \in \{0,\dots,\frac{\mathrm{container}}{4} + 1-1\},\; \frac{4 \cdot n}{4} = n \land n - 2 + 2 = n = \mathrm{decide}\mathopen{}\left(2 \le n\right) \land \frac{\mathrm{container}}{4} = 32 \land \frac{\mathrm{version}}{4} = 1 \land \frac{\mathrm{container}}{4} - \frac{\mathrm{version}}{4} + 1 = 30

read as hex handles: 32 nibbles, less the one the version fills and the one the variant touches = 30 free. AS A LAW: at EVERY register of n whole nibbles up to the container's 32, a width of 4n bits reads back as n handles, and the two reserved handles subtract and restore (n − 2 + 2 = n) exactly when there are two to take (2 ≤ n) — below that the subtraction truncates and nothing is restored. 128 bits is the instance n = 32.

Proof. by decide — by evaluation; no domain is walked. □
