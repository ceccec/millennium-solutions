pauli_paths.lean ​

src/iso/iec-4879-quantum/pauli_paths.lean · namespace PauliPaths · 8 theorems · wing the floor

ℤ[ω], ω = e^{iπ/4}, as four integer coordinates on 1, ω, ω², ω³ with ω⁴ = −1. A 2×2 matrix is four entries a b c d (rows a b / c d); a 4×4 matrix is a function of row and column, the first tensor factor the high index bit. The Hadamard is unnormalised (H·H = 2·I) and √2 = ω − ω³ multiplies the T rules, so every equality is exact and integral.

No axioms, no Mathlib, no sorry.

Definitions

z0 := (0, 0, 0, 0)
z1 := (1, 0, 0, 0)
zi := (0, 0, 1, 0)        -- i = ω²
w1 := (0, 1, 0, 0)        -- ω
root2 := (0, 1, 0, -1)    -- √2 = ω − ω³
I2 := (z1, z0, z0, z1)
X2 := (z0, z1, z1, z0)
Y2 := (z0, zneg zi, zi, z0)
Z2 := (z1, z0, z0, zneg z1)
H2 := (z1, z1, z1, zneg z1)            -- unnormalised: H2·H2 = 2·I
S2 := (z1, z0, z0, zi)
T2 := (z1, z0, z0, w1)
bits4 := (List.range 16).map (fun i => (i % 2, i / 2 % 2, i / 4 % 2, i / 8 % 2))
wrongTX := add2 X2 Y2
wrongTY := add2 X2 (neg2 Y2)

conj2(H2,X2)=scale2((2,0,0,0),Z2)∧conj2(H2,Z2)=scale2((2,0,0,0),X2)∧conj2(H2,Y2)=scale2((−2,0,0,0),Y2)∧mul2(H2,H2)=scale2((2,0,0,0),I2)=true
(conj2 H2 X2 == scale2 (2, 0, 0, 0) Z2 && conj2 H2 Z2 == scale2 (2, 0, 0, 0) X2 && conj2 H2 Y2 == scale2 (-2, 0, 0, 0) Y2 && mul2 H2 H2 == scale2 (2, 0, 0, 0) I2) = true
