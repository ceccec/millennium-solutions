settled.lean ​

src/iso/690-record/settled.lean · namespace Settled · 8 theorems · wing the record

GENERATED by scripts/settled.ts — do not edit. Regenerate with npm run settled.

16 source files declare settledHere — the count of declarations that file closes by exhaustion. Until this file existed each was followed by theorem …_settles_its_range : settledHere = N := rfl, a constant compared to itself. seal-lean refused to seal every one of them as "a declaration, not algebra", so the numbers a reader quotes were hand-maintained with nothing checking them and a tautology standing where the check should have been.

THE TWO COLUMNS COME FROM INDEPENDENT READS OF THE SAME FILES. declared names the imported settledHere defs directly, so Lean reads each hand-set constant out of its own source; measured is written here by the generator from a parse of the by decide theorems. Nothing in this file can make them agree — adding a by decide theorem to any of them without bumping its count stops this file compiling.

WHAT THIS DOES NOT SAY: nothing here judges whether a count is the RIGHT measure of what a file settles, and nothing here checks the theorems themselves. It checks that a file's own declaration about itself matches its own contents. No axioms, no Mathlib, no sorry.

Theorem 1481 (every_file_settles_exactly_what_it_declares)sealed.

(declared.zip measured).all (fun p => p.1 == p.2) ∧ declared.length == measured.length ∧ declared.length == files.length ∧ declared.length == 16

── 1 · EVERY FILE SETTLES EXACTLY WHAT IT DECLARES ─────────────────────────────────────────────────────── The drift check, row by row. The left side is the constant in the source file; the right side is the count of its exhaustive theorems. This is the theorem the fifteen tautologies were standing in for.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 1482 (no_file_declares_more_than_it_holds)sealed.

(declared.zip theorems).all (fun p => p.1 ≤ p.2) ∧ (measured.zip theorems).all (fun p => p.1 ≤ p.2)

── 2 · AND NO FILE DECLARES MORE THAN IT HOLDS ─────────────────────────────────────────────────────────── The exhaustive theorems are a SUBSET of the theorems, so the declared count is bounded above by the total and the difference is the declarations closing some other way. A count exceeding the file's own theorems would be impossible rather than merely wrong, and that direction is now decided too.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 1483 (the_parts_sum_to_the_whole_and_each_part_is_recoverable)sealed.

declared.foldl (· + ·) 0 == measured.foldl (· + ·) 0 ∧ declared.foldl (· + ·) 0 == 291 ∧ (List.range declared.length).all (fun i => declared.foldl (· + ·) 0 - declared.getD i 0 == ((List.range declared.length).filter (fun j => j != i)).foldl (fun a j => a + declared.getD j 0) 0)

── 3 · THE PARTS SUM TO THE WHOLE, AND EACH PART IS RECOVERABLE ────────────────────────────────────────── Conservation with its inverse: the declared counts add to the same total the measured ones do, and removing any one file's count leaves exactly the rest — so no row can be quietly absorbed into another.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 1484 (no_file_settles_nothing)sealed.

∀n∈declared,0<n∧∀n∈measured,0<n
declared.all (fun n => 0 < n) ∧ measured.all (fun n => 0 < n)
LaTeX source
\forall n \in \mathrm{declared},\; 0 < n \land \forall n \in \mathrm{measured},\; 0 < n

── 4 · NO FILE SETTLES NOTHING ─────────────────────────────────────────────────────────────────────────── A file declaring zero would pass row 1 by holding no exhaustive theorem at all, which is agreement without content. Every count is positive, so every row above is a claim about something.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 1485 (the_counts_are_not_one_number_repeated)sealed.

1<|dedup(declared)|∧|dedup(declared)|=12∧fold(a,b↦(bifa<b;otherwisea),declared,0)>fold(a,b↦(bifb<a;otherwisea),declared,1000)
1 < declared.eraseDups.length ∧ declared.eraseDups.length == 12 ∧ (declared.foldl (fun a b => if a < b then b else a) 0) > (declared.foldl (fun a b => if b < a then b else a) 1000)
LaTeX source
1 < \left|\operatorname{dedup}\left(\mathrm{declared}\right)\right| \land \left|\operatorname{dedup}\left(\mathrm{declared}\right)\right| = 12 \land \operatorname{fold}_{a,\,b \mapsto \begin{cases}b & \text{if } a < b\\ a & \text{otherwise}\end{cases}}\left(\mathrm{declared},\, 0\right) > \operatorname{fold}_{a,\,b \mapsto \begin{cases}b & \text{if } b < a\\ a & \text{otherwise}\end{cases}}\left(\mathrm{declared},\, 1000\right)

── 5 · THE CONTROL: THE AGREEMENT IS NOT ONE NUMBER REPEATED ───────────────────────────────────────────── THE THEOREM THAT STOPS ROW 1 FROM BEING VACUOUS. Row-wise equality between two lists would hold trivially if every entry were the same value, so it is decided here that the counts genuinely differ: the distinct values number more than one, and the extremes are far apart. Without this, a generator that emitted a constant column would read as green.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 1486 (each_file_is_counted_once)sealed.

|dedup(files)|=|files|∧|files|=16
files.eraseDups.length == files.length ∧ files.length == 16
LaTeX source
\left|\operatorname{dedup}\left(\mathrm{files}\right)\right| = \left|\mathrm{files}\right| \land \left|\mathrm{files}\right| = 16

── 6 · AND EACH FILE IS COUNTED ONCE ───────────────────────────────────────────────────────────────────── Two rows for one file would double it in the total while every row still agreed with itself. The names are distinct, so the sum above is over fifteen files and not fourteen files and a repeat.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 1487 (the_two_proof_styles_partition_the_theorems)sealed.

((measured.zip byOther).map (fun p => p.1 + p.2)) == theorems ∧ measured.foldl (· + ·) 0 + byOther.foldl (· + ·) 0 == theorems.foldl (· + ·) 0 ∧ (measured.zip theorems).all (fun p => p.1 ≤ p.2)

── 7 · THE TWO PROOF STYLES PARTITION THE THEOREMS, AND NEITHER IS A DECLARATION ───────────────────────── What is not closed by exhaustion is closed by a tactic block over a ∀ — a THEOREM, proved for every value. The two counts add to the file's total and neither overlaps the other, so "not by decide" and "a declaration" are different things and the difference is decided here rather than assumed.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 1488 (no_declaration_in_these_files_closes_by_rfl)sealed.

byRfl.all (fun n => n == 0) ∧ byRfl.foldl (· + ·) 0 == 0 ∧ ((theorems.zip measured).map (fun p => p.1 - p.2)) == byOther

── 8 · AND NOT ONE DECLARATION IN THESE FILES CLOSES BY rfl ─────────────────────────────────────────────── THE THEOREM THAT FALSIFIES A SENTENCE THIS DEPOSIT WAS PUBLISHING. scripts/pages.ts wrote, on the README and the index, "the remaining N close by rfl and are declarations", computing N as the total less the by-decide count — which treats every proof that is not an exhaustion as an rfl declaration. They are not: they are ∀-quantified theorems. Among the 16 that declare a count the rfl total is zero, so the sentence named a population that does not exist — every genuine rfl declaration that used to live in them was a `settledHere = N` tautology, and each one is gone. What that subtraction actually counts is byOther, and THAT is the conjunct below: the quantity pages.ts labelled rfl equals the ∀-proved theorems at every row, so the label was wrong about every one of them.

Proof. by decide — by evaluation; no domain is walked. □
