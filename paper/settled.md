## `settled.lean`

<p class="paper-src"><code>src/iso/690-record/settled.lean</code> · namespace <code>Settled</code> · 8 theorems · wing <code>the record</code></p>

GENERATED by scripts/settled.ts — do not edit. Regenerate with `npm run settled`.


16 source files declare `settledHere` — the count of declarations that file closes by exhaustion.
Until this file existed each was followed by `theorem …_settles_its_range : settledHere = N := rfl`, a
constant compared to itself. seal-lean refused to seal every one of them as "a declaration, not algebra",
so the numbers a reader quotes were hand-maintained with nothing checking them and a tautology standing
where the check should have been.

THE TWO COLUMNS COME FROM INDEPENDENT READS OF THE SAME FILES. `declared` names the imported
`settledHere` defs directly, so Lean reads each hand-set constant out of its own source; `measured` is
written here by the generator from a parse of the `by decide` theorems. Nothing in this file can make them
agree — adding a `by decide` theorem to any of them without bumping its count stops this file compiling.

WHAT THIS DOES NOT SAY: nothing here judges whether a count is the RIGHT measure of what a file settles,
and nothing here checks the theorems themselves. It checks that a file's own declaration about itself
matches its own contents. No axioms, no Mathlib, no sorry.

<p class="thm-remark">── 8 · AND NOT ONE DECLARATION IN THESE FILES CLOSES BY rfl ─────────────────────────────────────────────── THE THEOREM THAT FALSIFIES A SENTENCE THIS DEPOSIT WAS PUBLISHING. scripts/pages.ts wrote, on the README and the index, "the remaining N close by rfl and are declarations", computing N as the total less the by-decide count — which treats every proof that is not an exhaustion as an rfl declaration. They are not: they are ∀-quantified theorems. Among the 16 that declare a count the rfl total is zero, so the sentence named a population that does not exist — every genuine rfl declaration that used to live in them was a `settledHere = N` tautology, and each one is gone. What that subtraction actually counts is byOther, and THAT is the conjunct below: the quantity pages.ts labelled rfl equals the ∀-proved theorems at every row, so the label was wrong about every one of them.</p>
<p class="thm-proof"><em>Proof.</em> <code>by decide</code> — by evaluation; no domain is walked. <span class="qed">□</span></p>
