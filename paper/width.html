No axioms, no Mathlib, no sorry.

Definitions

isoFloor := 128                       -- the ISO post-quantum floor
widths := [4, 8, 16, 32]         -- qpu's four hexbit widths; width 4 is the 128-bit UUID

Theorem 142 (the_register_at_each_width)sealed.

reg[widths]=[122,246,494,990]∧∀w∈widths,reg(w)=32⋅w-w-2∧∀w∈widths,reg(w)=31⋅w-2
widths.map reg = [122, 246, 494, 990] ∧ widths.all (fun w => reg w == 32 * w - w - 2) ∧ widths.all (fun w => reg w == 31 * w - 2)
LaTeX source
\mathrm{reg}[\mathrm{widths}] = [122,\,246,\,494,\,990] \land \forall w \in \mathrm{widths},\; \mathrm{reg}\mathopen{}\left(w\right) = 32 \cdot w - w - 2 \land \forall w \in \mathrm{widths},\; \mathrm{reg}\mathopen{}\left(w\right) = 31 \cdot w - 2

── 1 · THE REGISTER AT EACH WIDTH, AND THE TWO FORMULAS AGREE ───────────────────────────────────────────

Proof. by decide — exhausting 4 cases. □

Theorem 143 (the_grover_exponent_at_each_width)sealed.

grover[widths]=[61,123,247,495]∧∀w∈widths,grover(w)=reg(w)2
widths.map grover = [61, 123, 247, 495] ∧ widths.all (fun w => grover w == reg w / 2)
LaTeX source
\mathrm{grover}[\mathrm{widths}] = [61,\,123,\,247,\,495] \land \forall w \in \mathrm{widths},\; \mathrm{grover}\mathopen{}\left(w\right) = \frac{\mathrm{reg}\mathopen{}\left(w\right)}{2}

── 2 · THE GROVER EXPONENT AT EACH WIDTH ───────────────────────────────────────────────────────────────

Proof. by decide — exhausting 4 cases. □

Theorem 144 (the_iso_floor_is_cleared_exactly_from_width_sixteen)sealed.

∀w∈widths,isoFloor≤grover(w)=16≤w∧grover(4)<isoFloor∧grover(8)<isoFloor∧isoFloor≤grover(16)∧isoFloor≤grover(32)
widths.all (fun w => (isoFloor ≤ grover w) == (16 ≤ w)) ∧ grover 4 < isoFloor ∧ grover 8 < isoFloor ∧ isoFloor ≤ grover 16 ∧ isoFloor ≤ grover 32
LaTeX source
\forall w \in \mathrm{widths},\; \mathrm{isoFloor} \le \mathrm{grover}\mathopen{}\left(w\right) = 16 \le w \land \mathrm{grover}\mathopen{}\left(4\right) < \mathrm{isoFloor} \land \mathrm{grover}\mathopen{}\left(8\right) < \mathrm{isoFloor} \land \mathrm{isoFloor} \le \mathrm{grover}\mathopen{}\left(16\right) \land \mathrm{isoFloor} \le \mathrm{grover}\mathopen{}\left(32\right)

── 3 · THE FLOOR IS A FUNCTION OF THE WIDTH: CLEARED EXACTLY FROM WIDTH SIXTEEN ───────────────────────── The 67-bit shortfall of the UUID is not fixed — it is the width-4 instance. Among the four widths the floor is cleared iff w ≥ 16; width 8 (a 256-bit identifier) still falls five bits short, which is why the name is 16.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 145 (clearing_the_floor_is_two_hundred_fifty_six_free_bits)sealed.

∀w∈widths,isoFloor≤grover(w)=256≤reg(w)∧reg(8)<256∧256≤reg(16)
widths.all (fun w => (isoFloor ≤ grover w) == (256 ≤ reg w)) ∧ reg 8 < 256 ∧ 256 ≤ reg 16
LaTeX source
\forall w \in \mathrm{widths},\; \mathrm{isoFloor} \le \mathrm{grover}\mathopen{}\left(w\right) = 256 \le \mathrm{reg}\mathopen{}\left(w\right) \land \mathrm{reg}\mathopen{}\left(8\right) < 256 \land 256 \le \mathrm{reg}\mathopen{}\left(16\right)

── 4 · AND THAT IS EXACTLY TWO HUNDRED FIFTY-SIX FREE BITS — capacity.lean's threshold, read on the width ──

Proof. by decide — by evaluation; no domain is walked. □

Theorem 146 (the_uuid_is_width_four_and_sits_sixty_seven_below)sealed.

reg(4)=122∧grover(4)=61∧isoFloor-grover(4)=67∧32⋅4=128
reg 4 = 122 ∧ grover 4 = 61 ∧ isoFloor - grover 4 = 67 ∧ 32 * 4 = 128

\mathrm{reg}\mathopen{}\left(4\right) = 122 \land \mathrm{grover}\mathopen{}\left(4\right) = 61 \land \mathrm{isoFloor} - \mathrm{grover}\mathopen{}\left(4\right) = 67 \land 32 \cdot 4 = 128

── 5 · THE UUID IS WIDTH FOUR — the 122 register, 67 below the floor, that the deposit already seals ──────

Proof. by decide — by evaluation; no domain is walked. □

Theorem 147 (the_register_grows_strictly_with_the_width)sealed.

reg(4)<reg(8)∧reg(8)<reg(16)∧reg(16)<reg(32)∧grover(4)<grover(8)∧grover(8)<grover(16)∧grover(16)<grover(32)

── 6 · THE DIAL ONLY TURNS UP: register and Grover exponent strictly increase across the widths ──────────

Theorem 148 (clearing_the_floor_needs_a_cost_exponent_of_at_least_256)sealed.

256≤reg(16)∧reg(8)<256∧2128<2256
256 ≤ reg 16 ∧ reg 8 < 256 ∧ 2 ^ 128 < 2 ^ 256
LaTeX source
256 \le \mathrm{reg}\mathopen{}\left(16\right) \land \mathrm{reg}\mathopen{}\left(8\right) < 256 \land 2^{128} < 2^{256}

── 7 · THE COST OF CLEARING IT: the register IS the amplitude exponent, so clearing needs ≥ 256 bits of it ─ A classical state-vector over the register is 2^(reg w) amplitudes. Clearing the floor means reg ≥ 256, i.e. at least 2^256 amplitudes — the same number as the security the floor asks for. Decided on the exponents.

Proof. by decide — by evaluation; no domain is walked. □

Theorem 149 (the_cost_exponent_is_more_than_the_square_root_exponent_at_every_width)sealed.

∀w∈widths,grover(w)<reg(w)∧∀w∈widths,reg(w)-grover(w)=reg(w)+12∧reg(4)-grover(4)<reg(32)-grover(32)
widths.all (fun w => grover w < reg w) ∧ widths.all (fun w => reg w - grover w == (reg w + 1) / 2) ∧ (reg 4 - grover 4) < (reg 32 - grover 32)
LaTeX source
\forall w \in \mathrm{widths},\; \mathrm{grover}\mathopen{}\left(w\right) < \mathrm{reg}\mathopen{}\left(w\right) \land \forall w \in \mathrm{widths},\; \mathrm{reg}\mathopen{}\left(w\right) - \mathrm{grover}\mathopen{}\left(w\right) = \frac{\mathrm{reg}\mathopen{}\left(w\right) + 1}{2} \land \mathrm{reg}\mathopen{}\left(4\right) - \mathrm{grover}\mathopen{}\left(4\right) < \mathrm{reg}\mathopen{}\left(32\right) - \mathrm{grover}\mathopen{}\left(32\right)

── 8 · THE CONTROL — CAPACITY IS NOT CAPABILITY ───────────────────────────────────────────────────────── The cost exponent (reg w) is always MORE than the square-root exponent (grover w = reg w / 2), by exactly half the register, and the gap WIDENS with the dial. So the width that clears the floor is the width that makes the simulation larger: raising it buys capacity and never a speedup. This is the control the whole file rests on — if raising the width ever made grover w ≥ reg w, capacity would have bought capability, and it never does.

Proof. by decide — by evaluation; no domain is walked. □
